## 📖 Giới thiệu

**HQL_Book** là một mạng xã hội mini được viết hoàn toàn bằng HTML, CSS và JavaScript thuần. Chạy trực tiếp trong trình duyệt, không cần cài đặt phức tạp, không cần backend, không cần database server.

Toàn bộ dữ liệu (bài viết, tin nhắn, bạn bè, hồ sơ) được lưu trong **IndexedDB** — tồn tại qua các lần refresh và tắt/mở trình duyệt.

## ✨ Tính năng

### 📝 Bảng tin (News Feed)
- Đăng bài viết dạng text
- Đính kèm ảnh, video, tệp bất kỳ (tối đa 50MB)
- Preview media trước khi đăng
- Like / bỏ like bài viết
- Xóa bài viết của mình
- Tải file đính kèm về máy
- Xem ảnh full màn hình

### 👥 Bạn bè
- Tìm kiếm người dùng theo tên hoặc username
- Kết bạn 1 click
- Danh sách bạn bè hiển thị ở sidebar trái
- Modal quản lý bạn bè
- Có sẵn 5 user demo để test

### 💬 Nhắn tin (Chat)
- Cửa sổ chat popup ở góc phải dưới
- Gửi text, ảnh, video, tệp
- Hiển thị ảnh/video inline trong khung chat
- **Auto-reply** giả lập người kia trả lời sau 1-3 giây
- Trạng thái online (chấm xanh)
- Hiển thị tin nhắn cuối cùng trong danh sách liên hệ
- Thời gian gửi tin nhắn

### 👤 Hồ sơ cá nhân
- Đổi tên hiển thị
- Đổi bio (giới thiệu)
- Đổi ảnh đại diện
- Avatar tự động cập nhật khắp giao diện
- Nút xóa toàn bộ dữ liệu

### 🎨 Giao diện
- Dark mode giống Facebook
- Responsive: mobile / tablet / desktop
- Mobile nav bar dưới cùng
- Toast notification
- Badge hiển thị số bạn bè + tin nhắn chưa đọc
- Animation mượt mà
